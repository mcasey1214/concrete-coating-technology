# Future flooring finish sample gallery

Do not populate a product gallery until Melissa confirms product names and supplies authentic sample photographs.

## Recommended placement

Place a finish-sample grid on `/services/` immediately after the existing “Let’s break it down” section, whose final card introduces flake and textured finishes, and before the “Not sure? Ask Melissa.” contact CTA. This lets visitors see verified finish choices after learning about coating types and before reaching the consultation prompt.

## Component approach

- Keep samples in a small data list with `name`, `image`, `alt`, and optional short `description` fields so Melissa can add, remove, or replace a sample without changing layout markup.
- Use square, optimized photographs of actual CCT flooring samples; do not use generic or generated swatches.
- Display the finish name and optional description below each photograph in a responsive grid that reduces from several columns to two and then one.
- Make each photograph a keyboard-operable button that opens the existing accessible lightbox with a useful dialog label, close control, Escape support, and focus return.
- Lazy-load thumbnails, provide explicit dimensions, and retain descriptive alt text.
